## 二、通用新排布模板（四张表同构）

```
① 热漂后静置（保留原值，不标）
② 再生 0.5 前的排水（保留原值 45/30，不拆，不标）
③ 再生进水（去"风机"）0.5L                      ← 黄 + 红字
④ 开门前再生静置 600s（自原静止拆 10 分前置）      ← 黄 + 红字
⑤ 进水排水（去"冷风"）2L                         ← 黄 + 红字
⑥ 排水 10                                        ← 黄
⑦ 进水排水（去"冷风"）2L                         ← 黄 + 红字
⑧ 排水 45（最后排水本身＝黄区终点）                ← 黄
⑨ 剩余静止（原静止 − 600 − 120）                  ← 绿
⑩ 自动开门 120s                                  ← 绿 + 红字
⑪… 后移的风机/静止 →「自动开门静止/风机」          ← 绿 + 红字
```

**守恒公式**：`原静止 = 600(前置) + 剩余静止 + 120(开门)`，配时同步拆
（例：1500 → 600 + 780 + 120，配时 25 = 10 + 13 + 2）

**行数变化**：Intensive 10→12 行、Glass 11→13 行、89Mins 9→11 行、Self-cleaning 7→9 行（各 +2 行）。

## 五、标记规则与 Q3 边界

- **黄填充**：前移区＝0.5 再生本身 → 最后排水本身（含）及之前
- **绿填充**：后移区＝最后排水之后（剩余静止、自动开门、后移的风机/静止）
- **红字**：自动开门相关的描述（Q1/Q2 三步 + 拆步静止 + 自动开门 + 后移步骤）
- **先清后标**：四张改的表先整表清除第二步的填充与红字，再按新规则重标；Rapid/Soak 整表清除且不再标
- **与双列区无关**：清除与重标**只作用于本体区 A..motor**（C 描述 / D 参数 / E–K 开关 / 配时列 / M 双速电机）。
  双列区（N..W，Self-cleaning 为 H..I）不参与标记清除，按新本体**整体重建**（累计/倒计时串），
  其自身颜色规则（进水蓝 / 黄填充行红字 / 端点绿）保持不变。
