# 第二步 · 时序表「描述 / 参数」定义与新旧核对报告

> 日期：2026-10-31
> 核对对象：**未维护的分栏**（90Mins / Soak / Self-cleaning）
> 已维护的 Intensive / Glass / Rapid **不参与本次核对**——它们是人为调整过的时序，差异属预期
> 数据源：旧＝`普通版从这里派生.xlsx`（45 机母表）／新＝`普通版.xlsx`（60 机）

---

## 一、定义

| 术语 | 文件中表头 | 列 | 含义 | 举例 |
|---|---|---|---|---|
| **描述** | 「步骤」 | **C 列** | **这一步做什么**（工艺动作） | `洗涤`、`进水`、`排水`、`静止`、`风机（非交替）` |
| **参数** | 「参数」 | **D 列** | **这一步的设定值**，单位隐含在写法里 | `3.9L`、`600`、`T55/420`、`60（大）` |

两者关系：**描述＝动作类别，参数＝该动作的具体数值**。改描述＝换动作；改参数＝调数值。

### 1.1 参数写法的语义（已逐项验证）

| 写法 | 含义 | 例 | 换算 |
|---|---|---|---|
| `纯数字` | **秒**（该动作时长） | `600` → cd 10 分 | ÷60 取整 |
| `数字L` | 升（水量） | `3.9L` | — |
| `T数字` | 目标温度 ℃ | `T69` | 用于「温达」判定 |
| `T数字/数字` | 温度 / 该温度保持的**秒数** | `T55/420` → cd 7 分 | 后半段 ÷60 |
| `数字（大）` | 分配器型号＝大 | `60（大）` | — |
| `数字（MINI）` | 分配器型号＝MINI | `1（MINI）` | — |

### 1.2 一条可用于校验的算术关系

> **描述的参数里的秒数 ÷ 60 = 该行的倒计时（分钟）**

全表逐行验证通过：`600→10`、`420→7`、`480→8`、`900→15`、`1140→19`、`1200→20`、
`180→3`、`240→4`、`840→14`、`360→6`、`540→9`、`300→5`。

这条关系可以用来**反向校验描述与参数是否自洽**——若某行参数秒数与 cd 对不上，说明该行被改动过。

## 二、核对方法 Sequence Alignment

90Mins 新旧两表的工序序列**长度不同**（45 机与 60 机工序数不等），
因此：

- ❌ 按**行位置**对齐 —— 中后段会整体错位
- ❌ 按**序号**对齐 —— 新版本身插过行，序号已重排
- ✅ 按「描述＋参数＋倒计时」三元组做**序列比对**（difflib）—— 正确做法

### 3.3 90Mins —— 发现一处描述误改 ⚠️

序列比对共 9 段差异，其中 **8 段是参数调整**（正常），**1 段是描述被改**（异常）：

```
[风机嫌疑]
  - 旧(行55) [风机] 参数=900  cd=15
  - 旧(行56) [风机] 参数=600  cd=10
  - 旧(行57) [风机] 参数=600  cd=10
  + 新(行54) [静止] 参数=900  cd=15
  + 新(行55) [静止] 参数=600  cd=10
  + 新(行56) [静止] 参数=600  cd=10
```

**参数与倒计时一字未改，唯独描述从「风机」变成了「静止」。**

#### 三条佐证

1. **45 机母表**此处明确写作 `风机`
2. **模板 Intensive / Glass** 的同一工艺段，`静止` 与 `风机（非交替）` 是**两个并存的不同步骤**：
   - `静止`＝电机不转（待机）
   - `风机（非交替）`＝风机运转（干燥）
3. 若干燥阶段没有风机，工艺上不成立

模板 Intensive 该段的形态：
```
再生进水风机 → 静止(1500) → 风机(600) → 风机(1200) → 冷风进水排水 → 排水 → 冷风进水排水 → 排水
```
90Mins 新版该段：
```
再生(电子可调) → 静止(900) → 静止(600) → 静止(600) → 进水(电子可调) → 排水 → 进水(电子可调) → 排水
```
（后两步按已确认的 B 项映射，将改写为「冷风进水排水」）

按模板对应关系：**第 1 个位置是静止，第 2、3 个位置应是风机**。
