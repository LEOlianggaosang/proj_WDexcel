## 一、三条交付线（互不越界）

| 文档 | 谁用 | 含什么 |

## 二、一张表长什么样

```
本机型（工作簿）
  └ 洗涤菜单 = 工作表标签
      └ 洗涤阶段 = B 列合并格：预洗 → 主洗 → 漂洗 → 干燥
          └ 洗涤步骤 = A 列序号
              ├ 步骤描述 = C 列
              └ 步骤参数 = D 列
  └ 电控可选功能 = E 列起开关矩阵
  └ 步骤倒计时配时 = 例 L 列
  └ 双速电机 = 例 M 列（预留项）
  └ 双列区 = 最右
```

**列位置是浮动的，必须现算**：开关矩阵 E 起 → 源倒计时 → 双速电机 → 双列区紧接其后。

| 分栏 | 开关矩阵 | 配时 | 电机 | 双列区 |
|---|---|---|---|---|
| Intensive / Glass / 89Mins | E–K (7 组) | L | M | N–W |
| Rapid | E–F (2 组) | G | H | I–L |
| Soak / Self-cleaning | E (1 组) | F | G | H–I |

## 三、参数在说什么

| 形式 | 例 | 语义 |
|---|---|---|
| `纯数字` | `排水 30`、`洗涤 600` | 动作时长（秒） |
| `数字L` | `进水 3.9L` | 目标水量，**到位即完成** |
| `T数字/数字` | `T50/360` | 50℃ / **360 = 整步总时长（秒）**，温达后不提前跳步 |
| `纯 T数字` | `T69` | 只给目标温度，**温达即跳步** |

**参数形式 → 加热类型**

| D 列形式 | 加热类型 |
|---|---|
| `T数字/数字` | 定温加热-**温达剩洗** |
| `纯 T数字` | 定温加热-**温达跳步** |
| `纯数字` | **定时加热** |

> 配时列**不是**参数 ÷60 机械算出来的，是人工配时值（取整方向还不一致）。详见 `规则手册.md`。

## 四、颜色在说什么（标记 = 「这行为什么被改过」的编码）

**填充色 = 改动性质**

| 色 | 性质 | 例 |
|---|---|---|
| 🟩 绿 | **结构性改动**：拆行、动作方式重写、参数性质变化 | `再生(电子可调) 120` → `再生进水风机 0.5L`（秒数变水量） |
| 🟨 黄 | **参数 / 描述级改动** | `T50` → `T50/360` |
| 无 | 仅数值微调 | 水量 3.4→3.9L、洗涤 1200→600 |

> 反查母表确证：**只改数值的行一律不着色**。只有改动**性质**变了才标色。

**填充横向范围 = 波及范围**

- **C–M 整行**：参数被改，波及开关矩阵 / 配时 / 电机
- **C–D**：只有描述与参数被改（如温达跳步，参数本身没变）

**红字 = 逐格点名被改的那个值**

`C`=描述 ｜ `D`=参数 ｜ `D+配时列`=两者 ｜ `D–M`=加热参数形式 ｜ `C+D`=描述与参数

**字体色**：红 = 需特别提示（定温加热，或逻辑与其他分栏不同处）｜蓝 = 进水类｜绿 = 端点（起值行、端行）
**灰填充**（双列区）：该组无此步骤。

## 五、双列区怎么读

`6/2:42` = 本步跑 6 分钟，跑完还剩 2 小时 42 分。

| 术语 | 位置 / 写法 |
|---|---|
| 累计列 | 每组 2 列中的第 1 列 |
| 倒计时列 | 第 2 列，组名也写在**这一列**（第 3 行） |
| 起值行 | 第 4 行写 `0/总时长` |
| 端行 | 统一写 `1/end` |

**倒计时列的字色（2026-11-02 恢复）**：蓝 = 进水类步骤 ｜ 红 = 本体黄填充行（加热类） ｜ 绿 = 端点（起值行 / `1/end`）。
**框线**：数据行无边框，只有名称行和起值行有框——干净好扫读。

## 六、版本谱系（2026-11-02 你亲述）

```
60机原始时序
 ├─ 旧版本.xlsx —— 改成 45机的版本
 │     改动依据：①进水量减少 ②加热温度更改并减少加热配时 ③风机调整配时
 │     改动痕迹：落在旧版本的「辅助栏 + 红字」里
 └─ 普通版.xlsx —— 先把数据恢复回 60机，再进行其他更改后的呈现版本（本项目处理对象）
```

> **两套标记体系别混**：旧版本的辅助栏/红字记录的是 **60→45 的差异**；
> 我们成品里的红字/填充记录的是**第二步的改动**。
> 反查「45机相对60机改了什么」→ 看旧版本辅助栏与红字。
> 旧版辅助列残留（如范围内六表曾被隐藏的 N 列）也属这段谱系的历史痕迹。
> **恢复60机也可能引入误改**（实证：89Mins 漂洗第一次加热，旧版本 T65/480 温达剩洗
> 被恢复成了定时加热 480，V18 已按裁决改回温达剩洗 T60/480）——凡"恢复"过的取值
> 都值得与旧版本同类行对一眼。

## 七、干燥 / 再生段两种模式（易错点）

| 模式 | 分栏 | 形态 |
|---|---|---|
| 强力/晶亮 | Intensive、Glass | `再生进水风机` → `静止`(长) → `风机`×2 → … |
| 89 分钟 | 89Mins | `再生` → `静止`×3 → … **不补风机** |

> 89Mins 的 **静止不补风机是有意设计，不是错误**。跨分栏对比时，形态不同 ≠ 错了。
