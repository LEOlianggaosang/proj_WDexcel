## 三、位置调整（业务原因与做法）

**原因**：自动开门后**断开强电，不能再进行负载动作**——所以开门后的步骤必须都是无负载的（静止/风机类）。

| # | 规则 |
|---|---|
| 1 | 步骤位置变动**参考自动门**（以 `自动门.xlsx` 的排布为准） |
| 2 | **保留热漂后静置**（如果有）；`再生0.5` 前的 `排水45` **不变** |
| 3 | **增加开门前再生静置**：若 `再生0.5` 后有静止步骤，则**拆 10 分钟前置**（原写 5 分钟，2026-11-02 用户改为 10 分钟） |
| 4 | 其后的 `再生进水` 与 `排水` 步骤**前移** |
| 5 | 剩余**没拆出的静止步骤**再拆出 **2 分钟**作为 `自动开门`，放在剩余静止时间**后面** |
| 6 | 其他后移的 `风机` 或 `静止` 步骤**后移到自动开门后** |

### U7 的算法：开关公因式提取（用户亲授）

再生间隔 X 必须是**所有分组都有的**风机时长（`X ≤ min(各组风机总时长)`）。

- 若存在**满开关风机步** → 直接扣（Intensive 2100[all]、Glass 1200[all]、自清洁 1200[all]）
- 若无满开关风机步（**89Mins**）→ 重组：
  `A = 6组(除Express)`、`B = {ED,Express}`、`C = {ED}`；`A∪B = 全开关`、`A∩B = C`
  由 `600·A + 600·B = 600·全开关 + 600·C` 得
  `900·A + 600·B + 600·C = 600·全开关 + 300·A + 1200·C`
  → **满开关一步 + 分开关两步**（风机900→300、600[ED,Ex]→0 删除、600[ED]→1200）

### 通用分组开关特征（由该策略归纳）

| 分组 | 含义 | 干燥段风机特征 | 为什么 |
|---|---|---|---|
| Null | 基准 | 基准风机步 | — |
| **ExtraDry** | 加强烘干 | **必最长**：全部风机步 + 专属附加步 | 名即"额外干燥" |
| **Energy(1/2)** | 半载 | 长风机步被缩短/替换（Glass 1500→1200 走专属行） | 半载含水少，干燥负担轻 |
| **Express** | 快速洗 | **跳过最长风机步**（89Mins 的 900 不执行） | 快速程序压缩干燥 |
| StrWash / MoreRinse / MorePre | 加强洗/多漂洗/多预洗 | 与 Null 完全一致 | 差异在水洗段 |

> 推论：干燥段差异只由 **ExtraDry（加）、Energy（减）、Express（跳）** 三者驱动。
