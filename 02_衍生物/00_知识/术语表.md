## 一、一张表怎么称呼

| 我们的叫法 | 指什么 | 表里怎么体现 |
|---|---|---|
| **工作簿 / 本机型** | 整份 Excel 文件 | 第 1 行标题。普通版＝「**欧洲60机**」，版本日期 **2026-08-19**（2026-11-02 经 MD5 实证：`01_源文件/普通版.xlsx` 与用户原件 `欧洲60机普通洗涤时序（20260819）.xlsx` 字节级相同，即最初版本） |
| **旧版本** | `01_源文件/旧版本.xlsx`：**60机改成45机**的版本 | 改动依据＝进水量减少、加热温度更改并减少加热配时、风机调整配时；差异记在**辅助栏与红字**。反查 60→45 改了什么就看它 |
| **分栏 / 洗涤菜单** | 一张工作表 | sheet 标签，如 `Intensive `、`89Mins` |
| **洗涤阶段** | 工序分段 | B 列合并单元格：预洗 → 主洗 → 漂洗 → 干燥 |
| **洗涤步骤** | 一行一步 | A 列序号 |
| **步骤描述** | 这步做什么 | C 列 |
| **步骤参数** | 设定值 | D 列 |
| **电控可选功能** | 会改变时序与总时间的开关 | E 列起的开关矩阵 |
| **步骤倒计时配时** | 这步耗时（分钟） | 例 L 列 |
| **双速电机** | **预留项**，与风机无关 | 例 M 列 |
| **双列区 / 衍生物** | 跑机对照用的输出区 | 表格最右侧 |

> **「双列区」「衍生物」这两个词表里没有**——是我们给它起的名。
> 「衍生物」的意思是：它不属于时序表本体，是你跑机时对着看的输出。

## 二、分组怎么叫

| 我们的叫法 | 含义 |
|---|---|
| **Null** | 默认时序（无附加功能） |
| **ExtraDry** / **StrDry** | 加强烘干。`StrDry` 是 1Hour 分栏的写法，其余表写 `ExtraDry` |
| **半载** | 见下方概念。`Energy(1/2)`、`1/2`、`WHR-HALF` 都是它 |
| **Express** | 快速 |
| **StrWash** | 加强洗 |
| **MoreRin / MorePre** | 多一次漂洗 / 多一次预洗。存在，但我们不建它的双列区 |

## 三、几个容易说岔的概念

**半载** —— 回答的是：机器**没有分层洗功能**时，用户只放一半餐具，时序该怎么处理。
是一个独立的时序分组。

> ⚠️ 我一度把 `Energy(1/2)` 理解成「节能」，错了。`Energy` 在这里是半载的意思，与节能无关。

**上下限** —— 指每个步骤**占总倒计时的允许区间**，不是温度的上下限。
每步耗时是一个区间而非定值，实机跑偏出界即异常——这是你跑机对照时的判读依据。

**MINI 变体续行** —— 同一工序的参数变体行，A 列序号为空。
它是「总时长多出 2 分钟」这类偏差的常见来源。

**第一份成品 / 第二份成品** —— 第一份＝`03_验收物/普通版_第二步已处理.xlsx`（普通版/欧洲60机，
已冻结，作基线与回溯依据）；第二份＝`03_验收物/自动门_第三步已处理.xlsx`（自动门版，由第一份派生）。
两套脚本、两份报告分开，**第三步不得写第一份**。

**模板 / 已维护分栏** —— 指 Intensive、Glass、Rapid 这三个人工调好的分栏。
我们用它们的标记**反推规则**，但**不拿它们做本体核对**（它们的时序是人为调过的）。

**回归校验** —— 用重建算法重生成一遍，跟源文件对比，看规则能不能复现人工标记。
