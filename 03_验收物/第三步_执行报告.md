## 〇、本次设计更新（2026-11-03）

| 项 | v2（上一版） | v3（本版） |
|---|---|---|
| 干燥段策略 | 静止拆分策略 | **再生间隔策略**（可调，当前拆 10 分钟风机为静止） |
| 成品一干燥段 | 含「风机改静止 + 拆分」 | **回退**为风机（V20），再生间隔 N=0 → 不拆 |
| 自动门前移 | 兼容静止拆分 | 兼容再生间隔：拆为 `静止（再生间隔）` + `自动开门` |
| 顺序 | 前置静止 → 前移 → 开门 | **0.5L → 再生间隔 → 前移 → 自动开门** |
| 89Mins +2 分钟 | 需要 | **取消**（公因式提取后天然守恒） |
| 自清洁/89 分栏特殊处理 | 需要 | **取消** |
| 自动开门描述 | `自动开门` | **`自动开门/静止`** |
| 底部备注 | `自动开门功能切换：…` | **`自动门开关切换：自动开门/静止、自动开门静止/风机`** |

**开关公因式提取**（用户裁决的核心算法）：再生间隔 X 必须是**所有分组都有的**风机时长。
若有满开关风机步则直接扣；若无（89Mins），用恒等式重组：
`A∪B = 全开关`、`A∩B = {ExtraDry}` ⟹ `600·A + 600·B = 600·全开关 + 600·{ED}`
