## 二、90→89 业务变更（自洽性已验证）

改的不是一处，而是**一串**，否则 A3 反推必然失败：

| 项 | 旧 | 新 |
|---|---|---|
| 工作表标签 | `90Mins` | **`89Mins`** |
| 菜单名 | `90min` | **`89min`** |
| Null 总时长 | 90 | **89** |
| 倒数第二步 冷风进水排水 配时 | 1 | **0** |

**为什么其余几组也必须 -1**：倒数第二步是每个分组都执行的物理步骤，抽掉 1 分钟后，所有分组的实际耗时同步减少。只改 Null 会让 A3 反推报错。

| 分组 | 旧标称 | 新标称 |
|---|---|---|
| Null | 90 | **89** |
| ExtraDry | 120 | **119** |
| Energy(1/2) | 75 | **74** |
| Express | 70 | **69** |
| StrWash | 105 | **104** |
| MoreRinse | 100 | **99** |
| MorePre | 100 | **99** |

> 六组 -1 已于 2026-11-01 由你确认。
