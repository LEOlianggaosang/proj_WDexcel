# README · 柜机时序表维护项目

洗碗机（柜机）**电控洗涤时序表**的维护项目。对象是整机厂共用的 Excel 工作簿：
一张表 = 一个洗涤菜单（Intensive / Glass / 89Mins / Rapid / Soak / Self-cleaning …），
逐行写清每个洗涤阶段每一步做什么、带什么参数、耗时多久。
**这份表最终是给电控工程师写程序用的。**

## 项目范围：你输入的 → 我处理的 → 我输出的

| 目录 | 性质 | 内容 |
|---|---|---|
| `01_源文件/` | **你输入的**（只读，我的脚本永不写） | `旧版本.xlsx`（母表，反查改动用，不需要更新）｜`普通版.xlsx`（处理对象，你拿它对照成品）｜`自动门.xlsx`（参考文件） |
| `02_衍生物/` | **我处理的中间态** | 知识、脚本、中间产物、图示、教学。**旧成品、旧报告归档在这里** |
| `03_验收物/` | **我输出给你的** | 最新成品（1 个 xlsx）+ 最新报告（1 个 md） |

> 验收流程：你验收后直接改源文件，**新版放根目录**，我吸收差异后删除。
> `01_源文件/` 只留最初始的三件，不建历史。

## 根目录四文件，各管一件事

| 文件 | 一句话 |
|---|---|
| **README.md** | 项目说明 + 怎么跑（本文件） |
| **PLAN.md** | 四步计划 + 当前待办 |
| **AGENT.md** | 约束集 + 改规则的通道（分底线/结论/习惯三层） |
| **INDEX.md** | 全部文件的地图 |

> 知识文档在 `02_衍生物/00_知识/`：`术语表.md`（交流用语，你查）、`模型理解.md`（结构语义，你查）、`规则手册.md`（实证与细节，我执行）。各 60–90 行。

## 三条交付线（互不越界）

| 文档 | 给谁 | 含什么 |
|---|---|---|
| **时序表** | 电控软件 | 机型 / 菜单 / 阶段 / 步骤 / 描述 / 参数 / 可选功能 / 配时 |
| **规格书** | 电控软件 | 面板交互规则与运行逻辑 —— **不在本项目范围** |
| **双列区（衍生物）** | 业主本人 | 实机跑机对照用的累计 + 倒计时串 |

## 快速开始

```bash
python 02_衍生物/01_脚本/_step2_body.py   # 本体：措辞改写 + MINI 清理 + 90→89 + 自校验
python 02_衍生物/01_脚本/_step2_cols.py   # 双列区重建
python 02_衍生物/01_脚本/_step2_fill.py   # 修补 + 填充 + 红字 + 模板回归
python 02_衍生物/01_脚本/_export_diff.py  # 导出逐行改写对照（供验收核对）
```

输入取 `01_源文件/`（只读），输出进 `03_验收物/`。
每步跑完会打印校验行，**全 OK 才继续**。

## 命名小记

`90Mins` 已于 2026-10-31 全量更名 **`89Mins`**（标签 / 菜单名 / 各组总时长），
起因是倒数第二步抽掉 1 分钟。详见 `03_验收物/第二步_执行报告.md`。
