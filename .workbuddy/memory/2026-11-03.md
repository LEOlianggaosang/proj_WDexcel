### 成品二（第三步）按再生间隔重排
核心算法＝**开关公因式提取**（用户亲授）：
再生间隔 X 必须是所有分组都有的风机时长（X ≤ min 各组风机总时长）。
- 有满开关风机步 → 直接扣（Intensive 2100、Glass 1200、自清洁 1200）
- 89Mins 无满开关步 → 用 `A∪B=全开关, A∩B=C={ED}` 恒等式重组：
  `900A+600B+600C = 600·全 + 300A + 1200C`
  → 风机900→300、600[ED,Ex]→0(删)、600[ED]→1200
- 顺序：**0.5L → 静止（再生间隔）480 → 前移 → 自动开门/静止120 → 自动开门静止/风机**
- 89Mins +2 分钟取消（Express 由 480+120=600 天然守恒）
- 自动开门 描述改为 **自动开门/静止**（字面照写）；底部备注
  **自动门开关切换：自动开门/静止、自动开门静止/风机**
